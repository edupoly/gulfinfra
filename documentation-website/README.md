# GulfInfraHub Documentation Website

This folder contains a self-contained documentation website for the GulfInfraHub application.

## Open locally

Open `index.html` directly in a browser, or serve this folder with any static web server.

## Structure

- `index.html` — application shell and accessible layout
- `styles.css` — responsive visual design
- `content.js` — structured documentation content
- `app.js` — sidebar, routing, search and previous/next navigation

Documentation routes use URL hashes, so individual sections can be bookmarked and shared without server configuration.
